## 📌 Project Overview

This project was developed as an undergraduate thesis. The application uses marker-based AR technology to display 3D models of traditional Kutai food in an interactive Android environment.

## 🍽 Featured Traditional Foods

This application introduces six traditional Kutai foods:
- Gence Ruan  
- Nasi Bekepor  
- Sambal Raja  
- Pulut Nasi Sanga Cabe Keli  
- Gangan Pisang Suah Jukut Salai  
- Rojak Jukut Keli  

## 🎯 Objectives

- Introduce traditional Kutai food through immersive technology  
- Support cultural preservation using Augmented Reality  
- Provide educational content including cooking recipes   

## 📱 Platform

- Android (APK-based application)  
- Not available for iOS  

## 🛠 Technologies Used

- Unity (AR Development)  
- Blender (3D Modeling)  
- C#  
- Android SDK 

## ⚙ Development Method

This project follows the Multimedia Development Life Cycle (MDLC) method, which includes:

1. Concept  
2. Design  
3. Material Collecting 
4. Assembly  
5. Testing  
6. Distribution  

## 📱 Features

- Marker-based AR detection  
- Real-time 3D food visualization  
- Interactive food information display  
- Detailed cooking recipe for each food  
- Mobile performance optimization

## 🌏 Cultural Context

Traditional Kutai food represents local heritage from East Kalimantan, Indonesia. This application aims to preserve and promote regional culinary culture through immersive digital experiences.
